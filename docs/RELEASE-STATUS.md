# Beta status

KiCad WebView is a read-only browser viewer for supported KiCad and fabrication inputs. See the [documentation](https://wayri.github.io/kicad-webview/docs/) and [demos](https://wayri.github.io/kicad-webview/), and consult [compatibility](KICAD-COMPATIBILITY.md) for format limits.

The source release is 0.1.0-beta.2 and is licensed under [MPL-2.0](../LICENSE), subject to the separate third-party and fixture terms described in [LICENSING.md](../LICENSING.md). The existing website uses 0.1.0-beta.1 and retains its earlier license. The npm package has not been published.

Slack and Notion web clients have been tested with interactive HTML snapshots; physical mobile clients remain unverified. The Confluence Forge adapter has not been deployed. See [integration setup](APP-INTEGRATIONS-BETA.md) and [browser validation](BROWSER-CHECKS.md) for scope and limitations.

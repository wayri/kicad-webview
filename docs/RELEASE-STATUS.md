# Release status

**Next release is paused.** Local stability work, docs and example changes are unreleased; no new npm/CDN/site version is advertised. See [next stability update](STABILITY-NEXT.md).

The current source prepares **KiCad WebView 1.1.0** (unpublished candidate) with the documented core embed API **1.0**. Package version, source revision and integrity are distinct from npm publication and CDN propagation. Verify each distribution channel before advertising its new version as available; preparing a package does not publish it.

See [1.1.0 candidate notes](RELEASE-1.1.0.md), [candidate validation](QA-1.1.0.md), [1.0.0 release notes](RELEASE-1.0.0.md), [API compatibility](API-STABILITY.md), and [validation scope](QA-1.0.0.md). Existing immutable releases retain their original bytes. Altium and application integrations retain their explicit experimental/host-validation limits.

The library remains a read-only viewer under MPL-2.0, free to use including commercially. Paid embedding, customization, maintenance and support are optional. Hardware examples and component models retain their own licenses and attribution.

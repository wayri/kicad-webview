# Beta status

KiCad WebView 0.1.0-beta.3 is the MPL-2.0 npm beta. Use the beta dist-tag or an explicit version. See the [npm package](https://www.npmjs.com/package/@wayrisignals/kicad-webview), [documentation](https://wayri.github.io/kicad-webview/docs/) and [current demos](https://wayri.github.io/kicad-webview/). Separate third-party terms remain in [LICENSING.md](../LICENSING.md).

This release includes the legacy footprint identity fix for component models and source selection. The npm artifact excludes legacy design fixtures and fixture-backed demo pages. The versioned website beta.2 SDK remains immutable; its current demonstrations can use additional host adapters.

Slack and Notion web clients have been tested with interactive HTML snapshots; physical mobile clients remain unverified. The Confluence Forge adapter has not been deployed. See [integration setup](APP-INTEGRATIONS-BETA.md) and [browser validation](BROWSER-CHECKS.md) for scope and limitations.

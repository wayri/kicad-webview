# KiCad WebView 0.8.0

Photoreal Fast, smooth Expand mode and source-colored net shine-through bring clearer assembly and connectivity inspection to embeds. Components lift first, copper layers separate, substrate fades and through vias stretch. Vias retain gold plating, including selected nets. Source geometry and saved identities remain unchanged.

Compact ribbon and inset controls give space back to the drawing. Copper clicks highlight the complete saved net by default and state that scope explicitly; the original object properties remain available. Linked selection events include the resolved saved net name. Accent highlighting is optional.

The extension refresh improves native schematic field orientation/justification, source loading, hierarchy, analytics and bounded inspection. A focused synthetic test reaches the last of 20,001 parts on a 32-layer input; this does not qualify full 3D rendering or device performance at every documented limit. See LARGE-PROJECTS.md.

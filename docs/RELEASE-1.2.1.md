# KiCad WebView 1.2.1

- Reuse the current drawing during 2D gestures and restore full detail when the gesture settles.
- Reduce render work during 3D camera motion and restore the selected quality when stationary.
- Inspect saved component classes and schematic rule-area directives, and highlight sheet-local net classes.
- Load supported embedded TrueType and OpenType fonts on demand and decode referenced embedded PCB models.
- Preview components in amber from either side of the linked 2D drawing and BoM.

Dynamic PCB class rules, custom DRC expressions, and cross-sheet rule resolution still require native KiCad.

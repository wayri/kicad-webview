# Support KiCad WebView

Voluntary sponsorship helps maintain KiCad WebView as a free, open-source browser library for electronics.

[Support the project](https://wayri.github.io/kicad-webview/sponsor/)

## What sponsorship supports

- Browser compatibility, regression fixes and release maintenance.
- Mobile performance, responsive embeds and accessible controls.
- Schematic, PCB and 3D fidelity, with explicit rendering limits.
- Documentation, examples and reproducible validation fixtures.

The public issue tracker and release notes show the work being done. Sponsorship supports shared project maintenance; it does not purchase a specific feature, delivery date, response time or engineering certification.

## Free use and optional services

KiCad WebView remains free to use, including commercially, under MPL-2.0. Sponsorship does not change that license or grant rights to hardware examples, user designs or third-party trademarks.

Paid integration, customization, maintenance or support with agreed deliverables is a separate service. Contact [support.kivi@sigharmonic.com](mailto:support.kivi@sigharmonic.com) to discuss that work. Sponsorship is not required to use the library or report a bug.

## Recognition and privacy

Names and logos are added to project acknowledgements only with explicit permission. A funding platform's own visibility settings are separate. Sponsorship does not imply endorsement, preferential security handling or control over project decisions.

Please do not put payment, banking, tax or identity information in repository issues or pull requests. Use the funding provider's own secure forms for payment and account verification.

Code, documentation, compatibility fixtures and useful bug reports are also welcome; see [Contributing](CONTRIBUTING.md).

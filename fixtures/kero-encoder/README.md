# KERO Encoder demonstration

Yawar Badri (wayri) supplied the KERO Encoder design for this viewer. The PCB and six schematic sheets are byte-for-byte copies of the [pinned design](https://github.com/wayri/KERO/tree/7be8fef589bc28eee149323e3790ef95b0873032/encoder). Source paths, byte lengths and SHA-256 hashes are recorded in PROVENANCE.json. External component models are not bundled.

MPL-2.0 covers the viewer software. Consult the upstream project for hardware design terms.
